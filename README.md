# 矿石镇的攻略百科

新分支「编年史」（chronicle），因为这次的攻略从初代 SFC 平台的《牧场物语》开始写的。  
顺手把百科的网页版也重构了。

## 架构介绍

基于攻略内容在完成后，几乎不会修改的性质，网站改回纯静态的模式。  
但是内容的加载方式由 `<iframe>` 改为 `v-html`。

会同时兼顾 PC 和手机用户的体验。  

### 测试环境

仅适配主流环境下的显示效果，测试环境如下。

- 系统 `Windows 10` `macOS Sequoia` `Linux Mint 22`
- 显示器 `1920×1080` 分辨率
- 手机 `Xiaomi 15`
- 平板 `iPad Air (2024)`
- 浏览器 `Chrome` `Edge` `Firefox` `Safari`

如出现任何问题，欢迎提 [issues](https://github.com/mineraltown/wiki/issues)
